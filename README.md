# 🎓 GCOEN Campus Assistant

An AI-Inspired Campus Assistant developed as part of the Lenovo Leap AI Capstone Project.

## 📖 About the Project

GCOEN Campus Assistant is a web-based platform designed to provide students with quick access to academic resources, notices, events, placement information, and campus support services.

The project supports **United Nations Sustainable Development Goal (SDG) 4 – Quality Education** by improving accessibility to educational information.

## 🎯 Problem Statement

Students often struggle to find important academic information because it is distributed across multiple platforms such as websites, notice boards, social media groups, and messaging applications.

This project provides a centralized platform where students can easily access:

- Academic Resources
- Notices
- Events
- Placement Information
- Campus Support

## 💡 Solution

The Campus Assistant acts as a virtual assistant that helps students quickly find information related to:

- Admissions
- Departments
- Syllabus
- Notes
- Exams
- Placements
- Internships
- Library
- Scholarships
- Contact Information

## ✨ Features

### 🤖 AI-Inspired Chat Assistant
Provides instant responses to student queries.

### 📚 Academic Resources
Access syllabus, study notes, previous year papers, and practical manuals.

### 📢 Notice Dashboard
Displays important academic notices and announcements.

### 🎉 Events Section
Shows upcoming college events, workshops, and competitions.

### 💼 Placement Corner
Provides placement-related information and internship opportunities.

### 📱 Responsive Design
Works on desktop and mobile devices.
